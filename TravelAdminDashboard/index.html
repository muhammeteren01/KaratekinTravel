Uygulama başlatılamadı

Bu sayfa file:// ile doğrudan açıldıysa tarayıcı JavaScript modüllerini güvenlik nedeniyle yükleyemez ve ekran boş kalır. Proje bir geliştirme sunucusu üzerinden çalıştırılmalıdır: 

cd TravelAdminDashboard
npm install
npm run dev

Ardından terminalde görünen adresi (genellikle http://localhost:5173) tarayıcıda açın.

Sunucu üzerinden açtığınız hâlde bu mesajı görüyorsanız, tarayıcı konsolundaki (F12 → Console) ilk hatayı kontrol edin.
