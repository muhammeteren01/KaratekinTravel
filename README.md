# Karatekin Travel

Monorepo for Karatekin Travel platform.

## Projects

| Folder | Description |
|--------|-------------|
| `KaratekinTravelApp` | Mobile app (Expo / React Native) |
| `TravelAdminDashboard` | Admin dashboard (React) |
| `turlagitsin-api` | Backend API (.NET) |

## Getting started

Each project has its own README and dependency setup. Work inside the relevant folder.

```bash
# Mobile
cd KaratekinTravelApp && npm install

# Admin dashboard
cd TravelAdminDashboard && npm install

# API
cd turlagitsin-api
dotnet restore
```
